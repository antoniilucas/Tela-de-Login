# 🔐 Tela de Login – Projeto Front-End

Este projeto consiste em uma **tela de login moderna** desenvolvida com **HTML, CSS e JavaScript**, com foco em usabilidade, layout responsivo e interações visuais.

## 🧩 Funcionalidades

- ✅ Layout dividido em **duas partes (50% / 50%)**
  - **Esquerda:** formulário de login  
  - **Direita:** área de marketing/institucional
- ✅ **Validação de login** com JavaScript (simulada)
- ✅ **Toast de erro** (popup) ao digitar credenciais incorretas
- ✅ **Animação no botão** ao clicar
- ✅ **Texto dinâmico** no título (palavra que troca a cada 2 segundos)
- ✅ Inputs centralizados e com largura controlada
- ✅ Estilo moderno em modo escuro

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
  - Estrutura semântica
  - Formulário de login
- **CSS3**
  - Flexbox (`display: flex`)
  - Layout em colunas
  - Animações com `transition`
  - Pseudo-elementos (`::placeholder`)
  - Centralização e responsividade
- **JavaScript (Vanilla JS)**
  - Manipulação do DOM
  - Validação de formulário
  - Eventos (`submit`)
  - Animação de texto com `setInterval`
  - Toast de erro com `classList`

## 🎨 Recursos Visuais

- Layout dividido (login + marketing)

## 📌 Observação
